# Early Disease Detection
A healthcare classification project to predict the presence of disease based on patient health indicators.

## Objective
To assist in early medical intervention by predicting disease risk based on clinical data.

## Key Deliverables
* **Comparative Analysis:** Compared Logistic Regression, Decision Trees, and SVM models to determine the most effective algorithm.
* **Feature Analysis:** Identified critical health indicators (e.g., blood pressure, cholesterol) that drive model predictions.
* **Model Validation:** Evaluated model reliability using a Confusion Matrix to minimize False Negatives.

## Portfolio Insight
"By prioritizing the minimization of False Negatives, this model ensures that patients requiring care are correctly identified, making it a viable tool for clinical decision support."
